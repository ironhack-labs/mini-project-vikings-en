What is Object-Oriented Programming?

  • Objects - Things in the real world (like a car, person, or soldier)
  • Classes - Blueprints/templates to create objects
  • Properties - Characteristics (like health, strength, name)
  • Methods - Actions the object can do (like attack, receiveDamage)

Real Life Example 🚗

Blueprint: Car Design

⬇️

Properties: color, speed, fuel

Methods: drive(), brake(), honk()

Class 1: Soldier (Parent Class) 🪖

Properties:

  • health - How much life the soldier has
  • strength - How much damage they can deal

Methods:

  • attack() - Returns the soldier's strength
  • receiveDamage(damage) - Reduces health by damage amount
class Soldier:
    def __init__(self, health, strength):
        self.health = health
        self.strength = strength

    def attack(self):
        return self.strength

    def receiveDamage(self, damage):
        self.health -= damage

Understanding Inheritance 👨‍👦

  • Definition: A child class gets all properties and methods from the parent class
  • Benefit: No need to rewrite the same code!
  • Syntax: class Child(Parent):

Class 2: Viking (Child of Soldier) 🛡️

Inherits from Soldier:

  • health, strength, attack()

Adds New Features:

  • name - Vikings have names!
  • battleCry() - Returns "Odin Owns You All!"
  • receiveDamage() - Custom version with Viking's name
class Viking(Soldier): # Inherits from Soldier
    def __init__(self, name, health, strength):
        self.name = name
        super().__init__(health, strength) # Call parent

    def battleCry(self):
        return "Odin Owns You All!"

    def receiveDamage(self, damage):
        self.health -= damage
        if self.health > 0:
            return f"{self.name} has received {damage} points of damage"
        else:
            return f"{self.name} has died in act of combat"

Understanding super() 🦸

  • super() calls the parent class's methods
  • Used to access parent's __init__ method
  • Avoids repeating code from the parent class

How super() Works

# Without super() - BAD ❌
class Viking(Soldier):
    def __init__(self, name, health, strength):
        self.name = name
        self.health = health # Repeating code!
        self.strength = strength # Repeating code!

# With super() - GOOD ✓
class Viking(Soldier):
    def __init__(self, name, health, strength):
        self.name = name
        super().__init__(health, strength) # Let parent handle it!

Class 3: Saxon (Child of Soldier) ⚔️

Inherits from Soldier:

  • health, strength, attack()

Key Difference from Viking:

  • No name property - Saxons are anonymous
  • Custom receiveDamage() returns "A Saxon..." (not a specific name)
class Saxon(Soldier):
    def __init__(self, health, strength):
        super().__init__(health, strength)

    def receiveDamage(self, damage):
        self.health -= damage
        if self.health > 0:
            return f"A Saxon has received {damage} points of damage"
        else:
            return "A Saxon has died in combat"

Class 4: War (Battle Manager) ⚡

Properties:

  • vikingArmy - List of Viking objects
  • saxonArmy - List of Saxon objects

Methods to Add Soldiers:

class War():
    def __init__(self):
        self.vikingArmy = [] # Empty list
        self.saxonArmy = [] # Empty list

    def addViking(self, viking):
        self.vikingArmy.append(viking) # Add to list

    def addSaxon(self, saxon):
        self.saxonArmy.append(saxon) # Add to list
Slide 9 of 12

War Class: Attack Methods ⚔️

vikingAttack() - Viking attacks Saxon:

  • Choose random Viking and Saxon
  • Saxon receives damage = Viking's strength
  • Remove dead Saxon from army
  • Return the damage message
def vikingAttack(self):
    saxon = random.choice(self.saxonArmy) # Pick random
    viking = random.choice(self.vikingArmy)
    damage = saxon.receiveDamage(viking.attack())
    if saxon.health <= 0:
        self.saxonArmy.remove(saxon) # Remove dead
    return damage

saxonAttack() works the same way but reversed!

War Class: Check Winner 🏆

showStatus() - Who's winning?

  • Check if any army is empty
  • Return appropriate message
def showStatus(self):
    if len(self.saxonArmy) == 0:
        return "Vikings have won the war of the century!"
    elif len(self.vikingArmy) == 0:
        return "Saxons have fought for their lives and survive another day..."
    else:
        return "Vikings and Saxons are still in the thick of battle."

Logic:

No Saxons left → Vikings Win 🛡️

No Vikings left → Saxons Win ⚔️

Both armies alive → Battle Continues ⚡
