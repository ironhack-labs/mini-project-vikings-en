# Mini Project | Vikings

## Light introduction by 
## **Juan Álvaro Romero Olivares** and Rolling Stones Group

## The Proyect
Create a program that simulates a battle between Vikings and Saxons based on OOP using class inheritance and polymorphism

_-The Vikings and the Saxons are at War. Both are Soldiers but they have their own methods to fight. Vikings are ported to Python. YAY!!-_

## The Objetive
In this proyect we want to work hard to use and strengthen our knowledge of object-oriented programming with Python.

**_"Trying again and again will make you stronger and better"_**

## The Start

You will find the following files in the folder of this proyect:

- _`vikingsClasses.py`_
- _`1-testSoldier.py`_
- _`2-testVikings.py`_
- _`3-testSaxons.py`_
- _`4-testWar.py`_

Use your favorite code editor and open the file.

## The Challenge

We modified the base file `vikingsClasses.py` according to the program specifications to pass all the tests

## The Tests

The tests are designed to test the three necessary classes independently and then all together.

The files for testing the code are as follows: 1-testsSoldier.py, 2-testsVikings.py, 3-testsSaxons.py, and 4-testsWar.py, depending on which part we are going to test.

You only need to run each test in a terminal.

For example:

```bash
$ python3 1-testsSoldier.py --v
```
